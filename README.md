# PCB Design Workshop

## Description
Learn how to use KiCad by designing your own PCB from scratch. During the workshops, you'll learn how most digital electronic devices get designed, schematic and layout best practices, and be able to assemble, test, and use your board to do something!

### What will be taught
* Basic KiCad usage
* Schematic best practices
* Layout best practices
* Using soldering irons, multimeters, and oscilloscopes

### What will NOT be taught
* Basic electrical theory (Ohms law, parallel/series, etc.)
* Firmware development (if firmware is needed, it will be provided)
* Datasheets (covered, not in depth)

## Prerequisites
* Some basic electrical knowledge (1 yr electrical or active LEC member)
* A laptop >4GB RAM with KiCad preinstalled
* git or GitHub Desktop and a GitHub account

## Rough Schedule
* Day 1 (3-4 hrs, hybrid): Anatomy of a PCB (by making a keychain light)
* Day 2 (3-4 hrs, hybrid): Project design (Start and hopefully finish the chosen project)
* Day 3 (2-3 hrs, in-person): Assemble and test your board (firmware will be provided if needed)
